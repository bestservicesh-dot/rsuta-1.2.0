1. Présentation de RSuta

RSuta, éditée par BSH - Best Services and House, est une application d'apprentissage conçue pour les élèves et étudiants du Bénin, du CEP à la Licence professionnelle. Son cœur est un Prof IA au ton chaleureux de « grand frère » qui a enseigné 20 ans au CEG Godomey : il explique chaque exercice en 3 étapes (on comprend, on applique la méthode, on vérifie), adapte son langage au niveau de l'élève et termine toujours par un encouragement béninois.

L'élève peut photographier son devoir, taper un exercice, soumettre une épreuve complète, réviser ses cours, s'entraîner avec des quiz corrigés, préparer son examen (diagnostic, plan de révision, fiches, cartes mémoire, examens blancs notés sur 20) et écouter les explications. RSuta est un « prof qui ne dort pas » : disponible jour et nuit, même sans connexion internet.

Pour qui ?

  • Élèves du primaire qui préparent le CEP
  • Collégiens (BEPC) et lycéens (BAC A, B, C, D)
  • Étudiants de Licence professionnelle, toutes filières
  • Enseignants (devoirs de classe corrigés automatiquement, sans serveur)
  • Parents (rapport de progression imprimable) et écoles (compte administrateur)

Points forts

  • Fonctionne hors-ligne (cours, quiz, scan, prof, devoirs de classe)
  • Même application sur téléphone, tablette, ordinateur
  • Explications pas à pas, lecture vocale
  • Rapide et léger, aucune publicité
  • Données privées, stockées sur l'appareil

RSuta est construit sur une seule base de code web (HTML, CSS, JavaScript, sans dépendance réseau), emballée pour chaque plate-forme. Tout le traitement se fait sur l'appareil ; internet n'est utilisé que si l'utilisateur active le mode en ligne du prof.

Le moteur du Prof IA

Hors-ligne (toujours disponible)

Un moteur de résolution reconnaît l'exercice et produit une explication rédigée en 3 étapes, avec calculs exacts (fractions, racines) et vérification. Pour les sujets rédactionnels, il fournit méthode et plan détaillé adaptés au niveau. Réponse en quelques millisecondes.

En ligne (optionnel)

Si une API compatible OpenAI est configurée, le prof envoie l'énoncé avec le prompt système officiel RSuta et exige la réponse au format JSON. En mode Automatique, l'API n'est appelée que lorsque le moteur hors-ligne n'est pas assez sûr (dissertations, questions ouvertes complexes).

Sécurité et confidentialité

  • Mots de passe et réponses secrètes hachés (SHA-256 avec sel) ; code de récupération personnel.
  • Aucune donnée envoyée à un serveur RSuta ; la clé API reste sur l'appareil.
  • Politique de sécurité du contenu (CSP) stricte ; aucune ressource externe chargée.

5. Installation et premiers pas

Plate-formeInstallation
Windows — sans installationDécompresser RSuta.zip, ouvrir le dossier rsuta et double-cliquer sur Lancer-RSuta-Windows.bat. RSuta s'ouvre dans Edge ou Chrome (laisser la petite fenêtre noire ouverte). Astuce : dans Edge, menu « … » → Applications → Installer RSuta pour obtenir une icône sur le bureau.
Windows — application .exeAvec Node.js : npm install puis npm run dist:win → installateur RSuta-Setup-1.2.0-x64.exe et version portable dans dist/. Sans rien installer : publier le dossier sur GitHub, onglet Actions → Run workflow : l'exe et l'apk sont générés automatiquement.
AndroidInstaller le fichier .apk produit par GitHub Actions (autoriser « sources inconnues »). Ou bien ouvrir la version web sur Chrome et choisir « Ajouter à l'écran d'accueil ».
WebCopier le dossier app/ sur un hébergement HTTPS (serveur de l'école, Netlify, GitHub Pages…). Après la première ouverture, tout fonctionne hors-ligne.
Éditeur affichéSous Windows, « BSH - Best Services and House » apparaît comme éditeur dans Paramètres → Applications installées et dans les propriétés de RSuta.exe.
iPhone / iPadSafari → Partager → « Sur l'écran d'accueil », ou compilation Capacitor sur Mac (npx cap add ios).

Premiers pas en 5 minutes

  1. Créer son compte (choisir son niveau, ou cocher « Je suis enseignant(e) ») et recopier le code de récupération.
  2. Sur l'Accueil, toucher son parcours (ex. BEPC) puis une matière et une leçon.
  3. Faire le quiz du chapitre.
  4. Toucher Scan ton devoir, photographier un exercice, vérifier le texte, puis Résoudre.
  5. Écouter l'explication, demander un exercice similaire et répondre : le prof corrige.
  6. Dans Paramètres, toucher Préparer (mode hors-ligne) une fois avec internet.

💡 Configuration minimale : téléphone Android 8 ou plus récent / Windows 10 ou plus récent, navigateur récent (Chrome, Edge, Firefox, Safari). Taille de l'application : environ 9 Mo, dont 7 Mo pour le module de lecture des photos.
