9. Questions fréquentes et dépannage

RSuta fonctionne-t-il vraiment sans internet ?
Oui : cours, quiz, épreuves, scan (lecture des photos), Prof IA, voix et comptes fonctionnent hors-ligne. Pour la version web, ouvrir l'application une première fois avec internet (et toucher Paramètres → Préparer). Seul le mode « en ligne » du prof, optionnel, utilise internet.
La photo est refusée (« je vois flou »).
Se placer près d'une fenêtre ou d'une lampe, tenir le téléphone parallèle à la feuille, cadrer entre les 4 coins jaunes et attendre la mise au point. On peut aussi toucher Saisir le texte.
Les sujets types sont-ils des annales officielles ?
Non. Les {{N_EP}} sujets types et les examens blancs sont créés pour RSuta conformément au programme béninois ; chacun porte la mention « Sujet type (non officiel) ». Pour travailler une vraie annale, la soumettre via Épreuves → Soumettre (texte ou photo).
Comment bien utiliser le module Réviser ?
1) Faire le diagnostic ; 2) générer le plan et vérifier la date de l'examen ; 3) chaque jour, toucher Commencer sur l'Accueil (fiche + cartes + quiz du chapitre) ; 4) passer l'examen blanc express proposé chaque semaine ; 5) consulter les points faibles et recalculer le plan.
La page photographiée contient plusieurs exercices, je n'en veux qu'un.
Après la photo, encadrer l'exercice voulu avec le doigt puis toucher Lire la zone.
Le texte lu contient des erreurs.
Corriger directement dans la fenêtre « Vérifie le texte lu » avant de toucher Résoudre. L'écriture manuscrite peu lisible est plus difficile à lire que l'imprimé ; le mode en ligne avec « vision » améliore la lecture.
J'ai oublié mon mot de passe.
« Mot de passe oublié ? » sur l'écran de connexion : saisir le code de récupération ou la réponse secrète. À défaut, l'administrateur peut générer un mot de passe temporaire.
Le lecteur de QR de la classe ne s'ouvre pas.
Même cause que la caméra : autoriser l'accès. Sinon, coller le code RSD1… / RSR1… ou utiliser « Fichier .rsuta ».
La caméra ne s'affiche pas.
Autoriser l'accès à la caméra (navigateur ou paramètres du téléphone). Sinon, le bouton Scanner ouvre l'appareil photo du système, et « Importer une photo » reste disponible.
Pas de voix lors de l'écoute.
Vérifier le volume et installer une voix française (Android : Paramètres → Synthèse vocale ; Windows : Paramètres → Heure et langue → Voix). Choisir la voix dans Paramètres → Voix.
Le micro ne fonctionne pas.
La dictée dépend du navigateur (Chrome, Edge). Sinon, taper la question au clavier.
Changer de téléphone sans perdre ses données ?
Paramètres → Données → Exporter sur l'ancien appareil, puis Importer le fichier sur le nouveau.
Plusieurs élèves sur le même ordinateur ?
Oui : chacun crée son compte ; les progressions et devoirs sont séparés. Un compte administrateur peut gérer la salle.
Qui contacter en cas de problème ou pour un code Premium ?
L'éditeur BSH - Best Services and House : +229 01 48 52 45 90 • contact@bestservicesandhouse.site • www.bestservicesandhouse.site (aussi dans Profil → Aide et contact).
Comment changer de niveau (par exemple après le BEPC) ?
Profil → Modifier le profil → Niveau. Les cours, quiz et le langage du prof s'adaptent immédiatement.
Comment fonctionnent les points XP et les badges ?
Chaque activité rapporte des XP (leçon, quiz, devoir, exercice interactif, carte mémoire, défi du jour, examen blanc, devoir de classe). Les XP font monter de niveau (Débutant → Légende) ; chaque jour actif prolonge la série 🔥. 20 badges se débloquent automatiquement (première leçon, 100 % à un quiz, 7 jours d'affilée, niveau 10…). Tout se consulte dans « Mes progrès » (menu latéral ou carte du Profil).
Comment partager une bonne note ?
Bouton Partager sur le résultat d'un exercice, d'un quiz, d'un examen blanc ou depuis « Mes progrès » : RSuta dessine une image carrée (1080 × 1080) avec le score. Télécharger l'image puis l'envoyer sur WhatsApp / Facebook / TikTok. Aucune donnée ne quitte l'appareil.
Un enseignant peut-il utiliser RSuta avec toute sa classe, sans internet ?
Oui. Compte créé en cochant « Je suis enseignant(e) » : menu latéral « Ma classe » → Nouvelle classe → Nouveau devoir (exercices saisis ou générés, durée, date). Le devoir est partagé par code recopié au tableau, QR code ou fichier — le réseau n'est pas nécessaire. Les élèves l'ouvrent dans « Devoirs de classe », composent (chrono si prévu) et rendent. Chaque copie produit un code que l'enseignant importe d'un coup (collage multiple, QR, fichiers) ; les réponses à correction automatique sont notées immédiatement, le reste est à vérifier ; la moyenne et la réussite par exercice s'affichent, avec export Excel/CSV.
Le rapport pour les parents, c'est quoi ?
Menu « Mes progrès » (ou Profil) → bouton « Rapport pour les parents » : un bilan des 30 derniers jours (jours actifs, leçons, quiz, examens, maîtrise par matière, badges) avec des conseils, à imprimer ou enregistrer en PDF (bouton Imprimer).

10. Limites et évolutions

Limites actuelles (en toute transparence)

  • Écriture manuscrite : la lecture hors-ligne est excellente sur un énoncé imprimé ou bien écrit, moins fiable sur une écriture difficile ; le texte reste toujours modifiable.
  • Sujets rédactionnels hors-ligne : le prof fournit l'analyse, la problématique, le plan détaillé et la méthode, mais pas une rédaction complète ; celle-ci nécessite le mode en ligne.
  • Figures : RSuta trace lui-même les courbes et tableaux de ses corrections, mais un exercice reposant sur une figure du sujet (géométrie dans l'espace, lecture graphique) doit être décrit en texte.
  • Comptes locaux : les comptes et la progression sont propres à chaque appareil (export / import pour transférer). De même, dans une classe sans réseau, devoirs et copies voyagent par code / QR / fichier, pas par serveur central.
  • Contenu : les leçons et les {{N_EP}} sujets types suivent le programme béninois ; les sujets types sont non officiels (ils ne reproduisent pas d'annales) et chacun porte cette mention. Les annales officielles peuvent être soumises via « Épreuves ».
  • Dates d'examen : la date du compte à rebours est indicative ; la corriger dans « Mon plan » dès la publication du calendrier officiel.

Évolutions possibles

  • Synchronisation des comptes sur un serveur d'établissement (API REST sur le même schéma de base de données).
  • Paiement mobile (MTN MoMo, Moov Money) pour l'abonnement Premium.
  • Intégration d'annales officielles 2015-2024, sous réserve d'autorisation des ministères.
  • Explications vocales en fon, yoruba et bariba ; synchronisation optionnelle des classes via un serveur d'établissement (le maillage code / QR / fichier, 100 % hors-ligne, restera disponible).
